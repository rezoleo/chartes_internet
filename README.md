Chartes d'Utilisation du Réseau Internet
===================

![Build status](https://github.com/rezoleo/chartes_internet/actions/workflows/build-latex.yml/badge.svg)

Git de travail des chartes d'utilisation du réseau internet de Rézoléo.
Les chartes sont compilées par Github Actions. Si une release est créée, alors les PDFs sont ajoutés à la release. Sinon, ils sont simplement ajoutés aux artifacts.

Une charte doit être signée par l'utilisateur pour accéder au réseau internet, et ainsi devenir un adhérent connecté.
